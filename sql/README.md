# `stellaris.sql` — game data, not project code

`stellaris.sql` is generated by `stellaris-extract.py` from the files of an installed copy of
Stellaris. It contains Paradox Interactive's content: names, descriptions and other localised text,
and the game's numbers. That content is © Paradox Interactive AB. **This repository's licence
covers the code, not this file.**

It is committed so that a deployment can rebuild the database without the game files
(`../build-sqlite.sh`). To produce it yourself, run the extractor against your own installation
(see `../AGENTS.md`).

This is an unofficial fan project. It is not affiliated with, endorsed by or sponsored by Paradox
Interactive. Stellaris is a trademark of Paradox Interactive AB.
